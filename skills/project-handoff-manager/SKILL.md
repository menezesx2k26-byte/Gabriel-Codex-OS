# Project Handoff Manager

Create handoffs that reduce re-orientation cost.

## Goals
- Capture what matters.
- Separate completed work from pending work.
- Make the next step obvious.

## Workflow
1. Summarize the current objective.
2. Record completed work.
3. Record validations performed.
4. Record open issues or pending decisions.
5. Record the exact next recommended step.
6. Keep it compact and operational.

## Handoff structure
- current phase
- completed
- validated
- pending
- next action
